# Reporting problems

For a cooling-control failure, first return the affected output to a known working controller or BIOS profile. Keep the original configuration and minimal logs locally. Report the behavior and version without serial numbers or private captures.

Security-sensitive reports should use GitHub's private vulnerability reporting when enabled for the repository. Do not put credentials, personal data or a working exploit against another user's hardware in a public issue. This preview provides no guarantee of unattended cooling safety; its concrete failover limitations are described in docs/ARCHITECTURE.md.
